This repository contains all the files for my GNPS2 Exposome Library, which are found in the **GNPS2ExposomeLibrary** folder. The analog spectra (.mgf file) and their associated metadata (.csv file) are found in the **Analogs** folder and include analog spectra and metadata for as non-synthesis (includes exposures not classified as drugs) and synthesis (analogs of in-house synthesis library spectra; files are labeled as "synthesis") analogs. The exposure classification of reactants in the in-house synthesis libraries is in the **SynthesisLibraries** folder.
