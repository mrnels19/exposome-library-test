This repository contains all the files for my Exposome Library, which are found in the GNPS2ExposomeLibrary folder. The analog spectra and their associated metadata are found in the Analogs folder and are labeled as non-synthesis (includes exposures not classified as drugs) and synthesis (analogs of in-house synthesis library spectra). Exposure classification of the reactants in the in-house synthesis libraries is found in the SynthesisLibraries folder.
